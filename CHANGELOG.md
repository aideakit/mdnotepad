# Changelog

## 1.0.1

- Works with the 32-bit (x86) Notepad++ too, not only the 64-bit one
- One archive for people, `MDNotepad-<version>.zip`: the installer picks the plugin that matches Notepad++
- Plugins Admin archives for both: `mdnotepad-<version>-x64-plugins-admin.zip` and `...-x86-...`

## 1.0.0

First release.

- Markdown preview panel next to the Notepad++ editor, with the GitHub look
- Text can be edited in the preview; the changes go into the Markdown source
- Mermaid diagrams, relative images, heading links
- Light and dark theme, scroll sync, export to PDF
- **mn** toolbar button
- Installer: double-click, from Git, or one PowerShell command
